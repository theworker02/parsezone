# parsezone

Parse and reshape zone text streams with deterministic transforms.

**Site:** https://theworker02.github.io/parsezone/

## Install / run

```bash
git clone https://github.com/theworker02/parsezone.git
cd parsezone
node src/cli.js
node --test
```
